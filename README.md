# Hall of Mirrors

## Download

Clone the repository
```bash
git clone https://github.com/JustAundre/Hall-of-Mirrors.git
```

## Global Dependencies

Must be running Linux
- MacOS doesn't count.

Must have
- GNU Coreutils
- inotify-tools

*Basically* everything here will also depend on
- `main/general-conf/secure-env.sh`
- `main/general-conf/limits.conf`

Required MAIN shell
- Bash

Required MAIN Initialization System
- SystemD

## Installation

Refer to the respective `README.md`s for each of the directories in `main/`
